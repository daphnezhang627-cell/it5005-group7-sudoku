## Run locally

Use Python 3.12 and install `requirements-notebook.txt` for the Notebook, or `requirements.txt` for the app alone. Open the Notebook with a Jupyter kernel in this repository directory. Run the app with `streamlit run sudoku_app.py`.

The required course submission contains only `Sudoku_Assignment.ipynb`, `sudoku_solver.py`, and `sudoku_app.py` inside `Group7/`. The support files are needed for running the project but are excluded from that submission ZIP.

`logic_.py`, `utils.py`, the `atom` helper, and the Notebook's puzzle-loading function are unchanged from the teacher's files. Test scripts, detailed local evidence and historical backups referenced in the validation record remain in the complete local review project.

Changes to `main` are connected to the public Streamlit deployment. Use a separate branch and a pull request for code review before merging changes.
